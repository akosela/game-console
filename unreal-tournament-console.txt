UNREAL TOURNAMENT (1999) -- ORIGINAL UT99 CONSOLE COMMAND REFERENCE
==============================================================================

IMPORTANT:
Scope: original Unreal Tournament / Unreal Engine 1 PC releases. This file
does not use Unreal Tournament 2003/2004, later UE versions, or remasters as a
command reference.

==============================================================================
1. CONSOLE / CHAT / PLAYER
==============================================================================

SAY <message>
  Broadcasts a message to all players.

TEAMSAY <message>
  Broadcasts a message to teammates.

SETNAME <name>
  Changes player name.

SETTEAM <team>
  Changes team where allowed.

SUICIDE
  Kills the local player.

MENUCMD <menu> <item>
  Invokes a menu command/item.

==============================================================================
2. CHEAT MODE / PRACTICE
==============================================================================

IAMTHEONE
  Enables local cheat commands in single-player/practice contexts.

GOD
  Toggles god mode.

LOADED
  Gives the normal weapon set and ammunition.

ALLAMMO
  Fills ammunition for weapons already owned.

FLY
  Enables flying movement.

GHOST
  Enables no-clip flying movement.

WALK
  Returns to normal walking physics.

PLAYERSONLY
  Freezes non-player actors.

SLOMO <factor>
  Sets game speed; 1.0 is normal.

ADDBOTS <number>
  Adds bots.

KILLALL <class>
  Kills/destroys all actors of a specified class.

KILLPAWNS
  Kills pawn actors/bots.

SUMMON <class>
  Spawns an actor of the specified class.

VIEWCLASS <class>
  Cycles the camera through actors of a class.

==============================================================================
3. NETWORK / SERVER / ADMIN
==============================================================================

OPEN <url>
  Opens a local map or connects to a server URL.

DISCONNECT
  Disconnects from the current server.

RECONNECT
  Reconnects to the current/last server.

ADMINLOGIN <password>
  Logs in as administrator.

ADMINLOGOUT
  Logs out of administrator mode.

ADMIN <command>
  Executes a server command as administrator.

ADMIN SERVERTRAVEL <url>
  Changes the server to another map/game URL.

KICK <player>
  Kicks a player.

KICKBAN <player>
  Kicks and IP-bans a player.

==============================================================================
4. ENGINE / DISPLAY / DIAGNOSTIC
==============================================================================

BEHINDVIEW <0|1>
  Switches first/third-person camera.

FOV <degrees>
  Sets field of view.

STAT FPS
  Shows frame rate.

STAT NET
  Shows network statistics.

STAT GLOBAL
  Shows global engine statistics.

STAT RENDER
  Shows renderer statistics.

GETRES
  Lists available display resolutions.

FLUSH
  Flushes engine caches/resources.

MEMSTAT
  Displays memory usage.

OBJ LIST
  Lists loaded Unreal objects.

OBJ GARBAGE
  Forces garbage collection.

==============================================================================
5. USEFUL COMMAND-LINE PARAMETERS
==============================================================================

-log
  Starts UT with the log window visible.

-noddraw
  Disables DirectDraw support.

-nodsound
  Disables DirectSound support.

-nohard
  Disables hardware 3D support.

-nosound
  Disables sound.

-windowed
  Starts in windowed mode where supported.
