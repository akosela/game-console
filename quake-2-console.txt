QUAKE II (1997) / YAMAGI QUAKE II CONSOLE COMMAND REFERENCE
==============================================================================

IMPORTANT:
Scope: classic id Software Quake II through the official 3.20 PC codebase,
plus Yamagi Quake II as the explicitly selected modern runtime/source port.
Nightdive/KEX remaster commands and Yamagi Quake II Remaster are excluded.
Quake II has a large command/cvar registry; cmdlist and cvarlist on the actual
executable remain the best completeness check.

==============================================================================
1. DISCOVERY / CONSOLE / SCRIPTING
==============================================================================

cmdlist [filter]
  Lists registered console commands.

cvarlist [filter]
  Lists registered console variables.

condump <name>
  Dumps current console text to a .txt file.

clear
  Clears console text.

echo <text>
  Prints text to the console.

exec <file.cfg>
  Executes a configuration file.

alias <name> <commands>
  Defines a command alias.

bind <key> <command>
  Binds a key.

unbind <key>
  Removes one key binding.

unbindall
  Removes all key bindings.

set <cvar> <value>
  Sets or creates a console variable.

seta <cvar> <value>
  Sets a cvar and archives it to configuration.

toggle <cvar>
  Toggles a boolean cvar where supported.

==============================================================================
2. GAMEPLAY / CHEATS
==============================================================================

god
  Toggles god mode.

noclip
  Toggles collision-free flying movement.

notarget
  Toggles monster target acquisition against the player.

give all
  Gives the normal weapon/item set and ammunition.

give health
  Restores/gives health.

give weapons
  Gives all standard weapons.

give ammo
  Gives standard ammunition.

give armor
  Gives armor.

give <item>
  Gives the named item using its game item name.

kill
  Kills the player.

Useful original item names accepted by give include:
  - blaster, shotgun, super shotgun, machinegun, chaingun
  - grenade launcher, rocket launcher, hyperblaster, railgun, bfg10k
  - shells, bullets, cells, grenades, rockets, slugs
  - quad damage, invulnerability, silencer, rebreather, environment suit
  - adrenaline, bandolier, ammo pack, power shield
  - data cd, power cube, pyramid key, data spinner, red key, blue key

==============================================================================
3. MAP / SAVE / DEMO / GAME FLOW
==============================================================================

map <mapname>
  Starts a local game on the named BSP map.

gamemap <mapname>
  Changes map using Quake II's game transition/save-state path.

demomap <demo>
  Plays a demo through the map/demo command path.

record <name>
  Starts demo recording.

stop
  Stops demo recording.

save <name>
  Saves the current game.

load <name>
  Loads a saved game.

quit
  Exits the game.

==============================================================================
4. PLAYER / INVENTORY
==============================================================================

use <item>
  Selects/uses a named inventory item or weapon.

drop <item>
  Drops a named inventory item where allowed.

inven
  Opens the inventory screen.

invnext
  Selects the next inventory item.

invprev
  Selects the previous inventory item.

invuse
  Uses the selected inventory item.

invdrop
  Drops the selected inventory item.

weapnext
  Selects the next weapon.

weapprev
  Selects the previous weapon.

weaplast
  Returns to the previously used weapon.

wave <0..4>
  Plays a multiplayer hand gesture.

viewpos
  Prints current player coordinates and heading.

hand <0|1|2>
  Sets right-hand, left-hand, or centered weapon view.

fov <degrees>
  Sets field of view.

==============================================================================
5. NETWORK / SERVER
==============================================================================

connect <address>
  Connects to a server.

reconnect
  Reconnects to the current/last server.

disconnect
  Disconnects from a server.

status
  Displays server status.

serverinfo
  Displays server information cvars.

userinfo
  Displays local user information cvars.

pingservers
  Queries configured server sources.

kick <user>
  Kicks a client from a local/administered server.

say <message>
  Sends chat to all players.

say_team <message>
  Sends team chat.

sv_gravity <value>
  Sets server gravity.

deathmatch <0|1>
  Controls deathmatch mode.

coop <0|1>
  Controls cooperative mode.

skill <0..3>
  Sets skill for the next game/map load.

==============================================================================
6. RENDERING / SOUND / DIAGNOSTICS
==============================================================================

r_speeds <0|1>
  Displays renderer timing/poly statistics.

timerefresh
  Benchmarks rendering by rotating through a view.

screenshot
  Writes a screenshot.

imagelist
  Lists loaded images/textures.

modellist
  Lists loaded models.

soundlist
  Lists loaded sounds.

gl_ztrick <0|1>
  Controls the classic OpenGL z-buffer optimization.

gl_triplebuffer <0|1>
  Controls OpenGL triple buffering.

cl_shownet <value>
  Displays network-message diagnostics.

cl_showmiss <0|1>
  Displays prediction-miss diagnostics.

netgraph <0|1>
  Toggles the network performance graph.

==============================================================================
7. YAMAGI QUAKE II — SOURCE PORT ADDITIONS
==============================================================================

Yamagi Quake II is a conservative source port built on the original Quake II
code lineage. It preserves the original gameplay while adding bug fixes,
modern platform support, renderers, audio, input, and convenience features.

The original Quake II commands above remain relevant. The commands below are
Yamagi additions documented by the project.

cycleweap <weapon classnames>
  Cycles through a supplied weapon-priority list.

gamemode <sp|coop|dm|?>
  Switches between single-player, cooperative, and deathmatch modes.
  gamemode ? prints the current mode.

listentities <class...>
  Lists coordinates of entities. Classes include ammo, items, keys, monsters,
  weapons, and all.

listmaps
  Lists available maps from loaded packages and the active maps directory.

ogg <info|mute|play|skip|stop|toggle>
  Controls Yamagi's OGG/Vorbis music playback.

playermodels
  Lists available multiplayer player models.

prefweap <weapon classnames>
  Selects the first usable weapon from the supplied priority list.

spawnentity <classname> <x> <y> <z> [angle_x angle_y angle_z]
  Spawns an entity at the given coordinates.

spawnonstart <classname>
  Spawns an entity at the player start point.

teleport <x> <y> <z> [angle_x angle_y angle_z]
  Teleports the player to the supplied position.

viewpos
  Prints the player's current position.

vstr <cvar>
  Inserts the current value of a cvar as command text.

Useful Yamagi-specific or renamed cvars include:

vid_renderer <gl3|gles3|gl1|soft>
  Selects the renderer. gl3 is the default modern OpenGL 3.2 renderer; gl1 is
  the OpenGL 1.4 renderer and soft is the software renderer.

gl_texturemode <mode>
  Controls texture filtering for the OpenGL renderers. GL_NEAREST disables
  filtering and mipmaps; GL_NEAREST_MIPMAP_NEAREST keeps nearest texel and mip
  selection.

r_2D_unfiltered <0|1>
  Set to 1 to disable bilinear filtering on 2D elements such as the menu and
  HUD.

r_videos_unfiltered <0|1>
  Set to 1 to disable bilinear filtering on videos.

r_anisotropic <value>
  Controls anisotropic filtering for accelerated renderers.

r_hudscale <value>
  Scales the HUD. -1 selects the automatically calculated scale.

crosshair_scale <value>
  Scales the crosshair independently from the HUD.

crosshair_color_r <0..1>
crosshair_color_g <0..1>
crosshair_color_b <0..1>
  Set the red, green, and blue crosshair color components.

cl_gun <0|1|2>
  Controls the first-person weapon model. 0 hides it, 1 uses the original
  FOV-dependent behavior, and 2 always draws it.

cl_async <0|1>
  Allows rendering to run independently from client/server simulation frames.

vid_maxfps <value>
  Sets Yamagi's rendering-frame-rate limit.

ogg_enable <0|1>
  Enables or disables OGG/Vorbis music playback.

aimfix <0|1>
  Enables Yamagi's optional aiming-accuracy fix.

Yamagi's official cvar documentation notes that all cvars can be supplied with
+set on the command line or entered directly in the console. Left Shift + Esc
is the documented console key combination.
