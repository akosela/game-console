VIETCONG (2003) -- ORIGINAL PC CONSOLE / CHEAT COMMAND REFERENCE
==============================================================================

IMPORTANT:
Scope: Pterodon/Gathering's original Vietcong 1 PC game. Fist Alpha-only
weapon additions and later Vietcong titles are not used for the base list.

  Dir        Campaign / mod  Developer                      Released
  vietcong   Vietcong        Pterodon / Illusion Softworks  2003
  fistalpha  Fist Alpha      Pterodon / Illusion Softworks  2004
  reddawn    Red Dawn        Pterodon                       2005

==============================================================================
1. CONSOLE / CHEAT ACTIVATION
==============================================================================

Press ~ (or the local keyboard key mapped to the console, commonly ^ on German
layouts) during play. Enter the master code first:
GIFTFROMPTERODON
  Enables the single-player cheat commands in the original game.

==============================================================================
2. SINGLE-PLAYER CHEATS
==============================================================================

CHTKOSTEJ
  Toggles/activates invulnerability.

CHTHEAL
  Restores player health.

CHTHEALTEAM
  Restores health for the player's team.

CHTAMMO
  Refills ammunition.

CHTGRENADES
  Gives grenades.

CHTWEAP <0..30>
  Selects/gives a weapon by numeric weapon index.

CHTALLQF
  Unlocks/accesses all Quick Fight maps.

CHTCANNIBALS
  Makes VC/NVA models wear the special mask effect.

CHT3PV <0|1>
  Toggles third-person view.

SHOWFPS <0|1>
  Toggles frame-rate display.

SHOWPROF <0|1>
  Toggles engine/profiling statistics.

==============================================================================
4. MULTIPLAYER / SERVER NOTE
==============================================================================

Vietcong also has server-administration console commands, but lists on the
modern web often mix base Vietcong, later patches, Fist Alpha, and third-party
server wrappers. This reference intentionally keeps the well-documented
original client/game commands separate rather than claiming a mixed server
list is executable-level complete.
