Welcome to Game Console

Reference documentation for console commands and old-school presentation settings in classic PC games.

About

This project collects practical command references for game consoles and developer modes, together with methods for removing HUD/crosshair elements and disabling texture filtering for a sharp, pixelated look.

The focus is on original games and original engines whenever possible. Remaster-only commands are intentionally avoided. EDuke32 and NewDark are documented where they are explicitly part of the target runtime.

Console references

Each reference covers console access, commands, cheats, debugging facilities and important build-specific notes.

    Presentation guides

      Scope

      • Prefer original-game commands and behavior.
      • Do not use remaster-only commands as references.
      • Keep source-port or engine additions clearly identified.
      • Distinguish native commands from config edits and wrappers.
      • Document limitations rather than invent unsupported commands.
