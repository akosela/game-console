RUNE (2000) — ORIGINAL UNREAL ENGINE 1 CONSOLE COMMAND REFERENCE
==============================================================================

  Dir   Campaign / mod           Developer           Released
  rune  Rune                     Human Head Studios  2000
  rune  Rune: Halls of Valhalla  Human Head Studios  2001

IMPORTANT
------------------------------------------------------------------------------
Scope: original Rune PC / Rune Gold-era console behavior, including Halls of
Valhalla. Rune Classic uses the same Unreal Engine 1 foundation, but some
version-specific behavior can differ. Remaster-only commands are not used as
reference material here.

==============================================================================
1. ACCESSING THE CONSOLE / ENABLING CHEATS
==============================================================================

Press ~ (tilde) to open the full console. TAB can also open the one-line
command prompt in classic builds. Most cheat commands first require:

cheatplease
  Enables Rune cheat mode for the current level/session.

Cheat mode may need to be enabled again after a level transition.

==============================================================================
2. CORE CHEATS
==============================================================================

god
  Toggles god mode / player invulnerability.

invisible
  Makes the player invisible to enemies.

amphibious
  Gives effectively unlimited underwater air.

killpawns
  Kills enemy pawns in the current level.

playersonly
  Freezes non-player actors while leaving the player active. Enter it again
  to resume normal simulation.

==============================================================================
3. MOVEMENT / CAMERA / VIEW
==============================================================================

fly
  Enables flying movement.

ghost
  Enables no-clip movement through world geometry.

walk
  Returns the player to normal walking physics after fly or ghost.

behindview <0|1>
  Switches first/third-person camera. 0 gives first-person view and 1 restores
  the normal third-person view.

camerain
  Moves Rune's third-person camera inward. Repeated use can pull the camera
  into a practical first-person view and is convenient when bound to a key.

cameraout
  Moves the camera outward toward the normal third-person distance.

fov <degrees>
  Changes the current field of view. Rune's original 4:3 default is 75.
  Example:
  fov 91.3

The console FOV can be reset by level changes or scripted camera changes. For
persistent gameplay FOV, edit DesiredFOV and DefaultFOV in System\User.ini.

Example camera bindings in System\User.ini:

  C=camerain
  V=cameraout

==============================================================================
4. HUD / DISPLAY / DEBUG
==============================================================================

set engine.hud hudmode 0
  Disables the gameplay HUD through the stock Unreal Engine HUD property.

stat fps
  Displays the frame-rate/performance counter.

togglefullscreen
  Toggles fullscreen/windowed mode.

preferences
  Opens the Unreal Engine advanced-options/preferences window where supported.

demorec <file>
  Starts recording a client demo.

6. HALLS OF VALHALLA (2001)
==============================================================================

Halls of Valhalla uses the same Rune console and core commands. The expansion
adds Arena and HeadBall multiplayer modes while retaining RuneMatch and Team
RuneMatch maps.

open ar-aeternal
  Loads the Halls of Valhalla Arena map AEternal.

open hb-agora
  Loads the Halls of Valhalla HeadBall map Agora.

open dm-acidchamber
  Loads the Halls of Valhalla RuneMatch/Team RuneMatch map Acid Chamber.

==============================================================================
7. CONFIGURATION / BINDING NOTES
==============================================================================

Rune stores console and input configuration in the System directory. User.ini
can bind console commands directly to keys.

Example:

  C=camerain
  V=cameraout
  F=fov 91.3

Persistent gameplay FOV is stored in System\User.ini under the player-pawn
settings. The original 4:3 values are:

  DesiredFOV=75.000000
  DefaultFOV=75.000000

For 16:9, 91.3 preserves approximately the original 4:3 vertical view.

Rune.ini identifies the console class as:

  [Engine.Engine]
  Console=RMenu.RuneConsole

Rune's game HUD class is RuneI.RuneHUD.
