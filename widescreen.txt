WIDESCREEN / FOV CONFIG REFERENCE
==============================================================================

SCOPE
------------------------------------------------------------------------------
Scope: the 18 games currently documented by the game-console repository.
The goal is to use the requested horizontal FOV mapping at 4:3, 5:4, and
16:9.  1920x1080, 2560x1440, and 3840x2160 are all 16:9 and use the same FOV.

Reference values used by this document:

  4:3  (800x600)    fov: 90
  5:4  (1280x1024)  fov: 86.3048
  16:9 (1920x1080)  fov: 106.2602
  16:9 (2560x1440)  fov: 106.2602
  16:9 (3840x2160)  fov: 106.2602

Unless stated otherwise, "FOV" below means horizontal FOV in degrees.  Some
engines use a different unit, a vertical FOV, or automatic Hor+ scaling; those
cases are called out explicitly.  The values above are the requested project
baseline even when a game's stock/default FOV is different.
==============================================================================
01. DUKE NUKEM 3D (1996) -- EDuke32
==============================================================================

EDuke32 supports arbitrary resolutions.  The video mode can be selected from
Setup / Video Setup or changed from the console.

4:3:

  vidmode 800 600 32 1
  FOV: 90

5:4 (1280x1024):

  vidmode 1280 1024 32 1
  leave Aspect Ratio on Auto
  FOV: 86.3048

16:9 (1920x1080):

  vidmode 1920 1080 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.2602

16:9 (2560x1440):

  vidmode 2560 1440 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.2602

16:9 (3840x2160):

  vidmode 3840 2160 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.2602

Set FOV in the EDuke32 display options.  Modern EDuke32 exposes the gameplay
FOV in degree-style units with 90 as the default.

Older Polymer-only builds expose r_pr_fov instead.  That command uses BUILD
angle units, not degrees: 512 is about 90 degrees.  The requested 16:9 value
cannot be represented exactly by that integer-style scale; about 605 BUILD
units is the nearest value.  Do not enter 106.2602 into r_pr_fov.
==============================================================================
02. QUAKE (1996) -- Mark V
==============================================================================

Use the Mark V source port.  Mark V v1099 Revision 4 supports modern
widescreen resolutions while retaining classic Quake behavior.

Mark V automatically applies Hor+ FOV adaptation.  Its "fov" cvar is the base
value that the engine adapts to the current render aspect ratio, so do not put
the already-widened project value 106.2602 directly into the cvar.

4:3:

  mark_v.exe -width 800 -height 600 +fov 90

5:4 (1280x1024):

  mark_v.exe -width 1280 -height 1024 +fov 90

16:9 (1920x1080):

  mark_v.exe -width 1920 -height 1080 +fov 90

16:9 (2560x1440):

  mark_v.exe -width 2560 -height 1440 +fov 90

16:9 (3840x2160):

  mark_v.exe -width 3840 -height 2160 +fov 90

Keep the Mark V base FOV at 90.  The engine's AdaptFovx() function widens the
horizontal view automatically for widescreen.  The same value can be entered
in the console or placed in autoexec.cfg.

Target convention for comparison:

  4:3  (800x600)    horizontal target: 90
  5:4  (1280x1024)  horizontal target: 86.3048
  16:9              horizontal target: 106.2602

Mark V uses its own native aspect-ratio FOV calculation, so keep fov at 90.
The resulting horizontal FOV is derived automatically for 5:4, 16:9, and
other aspect ratios rather than entered directly.
==============================================================================
03. QUAKE II (1997) -- Yamagi Quake II
==============================================================================

Use a custom video mode.  Yamagi normally has its own Hor+ correction, so turn
that correction off when supplying the final horizontal FOV explicitly.  This
prevents the engine from widening an already widened value.

4:3:

  set r_mode "-1"
  set r_customwidth "800"
  set r_customheight "600"
  set horplus "0"
  set fov "90"
  vid_restart

5:4 (1280x1024):

  set r_mode "-1"
  set r_customwidth "1280"
  set r_customheight "1024"
  set horplus "0"
  set fov "86.3048"
  vid_restart

16:9 (1920x1080):

  set r_mode "-1"
  set r_customwidth "1920"
  set r_customheight "1080"
  set horplus "0"
  set fov "106.2602"
  vid_restart

16:9 (2560x1440):

  set r_mode "-1"
  set r_customwidth "2560"
  set r_customheight "1440"
  set horplus "0"
  set fov "106.2602"
  vid_restart

16:9 (3840x2160):

  set r_mode "-1"
  set r_customwidth "3840"
  set r_customheight "2160"
  set horplus "0"
  set fov "106.2602"
  vid_restart

If using a build that exposes cl_widescreen_fov instead of horplus, disable
that automatic correction for the same reason before setting the final FOV.

04. UNREAL (1998)
==============================================================================

For reliable widescreen operation on current systems, the OldUnreal 227 patch
is recommended.  Resolution is stored in System\Unreal.ini; FOV is stored in
System\User.ini.

System\Unreal.ini, under the active viewport client section:

4:3:

  FullscreenViewportX=800
  FullscreenViewportY=600

5:4 (1280x1024):

  FullscreenViewportX=1280
  FullscreenViewportY=1024

16:9 (1920x1080):

  FullscreenViewportX=1920
  FullscreenViewportY=1080

16:9 (2560x1440):

  FullscreenViewportX=2560
  FullscreenViewportY=1440

16:9 (3840x2160):

  FullscreenViewportX=3840
  FullscreenViewportY=2160

System\User.ini, under [Engine.PlayerPawn]:

4:3:

  DesiredFOV=90.000000
  DefaultFOV=90.000000

5:4 (1280x1024):

  DesiredFOV=86.3048
  DefaultFOV=86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  DesiredFOV=106.2602
  DefaultFOV=106.2602

The console command "fov <value>" can be used for a quick test before making
the User.ini change permanent.

06. HALF-LIFE (1998) -- WON / RETAIL VERSION
==============================================================================

This section is deliberately for the original pre-Steam WON release, not the
25th Anniversary Steam build.

Install the Half-Life WON Resolution FOV MP3 Patch for the matching executable
version.  WON 1.1.1.0 is the usual final retail/WON build.  The patch enables
modern widescreen modes that the unmodified WON executable does not handle
properly.

The patch can include hl_fov_fix.asi, which automatically widens FOV according
to the current aspect ratio.  For the exact manual values in this document,
do not load hl_fov_fix.asi; otherwise the automatic correction and the manual
FOV can be applied together.

Launch examples:

4:3:

  hl.exe -gl -full -w 800 -h 600
  add: -lw 800 -lh 600 -noextracds -32bpp

5:4 (1280x1024):

  hl.exe -gl -full -w 1280 -h 1024
  add: -lw 1280 -lh 1024 -noextracds -32bpp

16:9 (1920x1080):

  hl.exe -gl -full -w 1920 -h 1080
  add: -lw 1920 -lh 1080 -noextracds -32bpp

16:9 (2560x1440):

  hl.exe -gl -full -w 2560 -h 1440
  add: -lw 2560 -lh 1440 -noextracds -32bpp

16:9 (3840x2160):

  hl.exe -gl -full -w 3840 -h 2160
  add: -lw 3840 -lh 2160 -noextracds -32bpp

Create or edit valve\autoexec.cfg:

4:3:

  default_fov 90

5:4 (1280x1024):

  default_fov 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  default_fov 106.2602

You can test the same values from the console with "default_fov <value>".

08. GOTHIC (2001)
==============================================================================

Use Union/SystemPack for reliable modern widescreen support.  Set resolution
in Gothic\System\Gothic.ini.

[VIDEO]

4:3:

  zVidResFullscreenX=800
  zVidResFullscreenY=600
  zVidResFullscreenBPP=32

5:4 (1280x1024):

  zVidResFullscreenX=1280
  zVidResFullscreenY=1024
  zVidResFullscreenBPP=32

16:9 (1920x1080):

  zVidResFullscreenX=1920
  zVidResFullscreenY=1080
  zVidResFullscreenBPP=32

16:9 (2560x1440):

  zVidResFullscreenX=2560
  zVidResFullscreenY=1440
  zVidResFullscreenBPP=32

16:9 (3840x2160):

  zVidResFullscreenX=3840
  zVidResFullscreenY=2160
  zVidResFullscreenBPP=32

SystemPack.ini does not expose the same horizontal-degree control used by the
reference values above.  It exposes VerticalFOV and calculates horizontal FOV
from the aspect ratio.  Keep Hor+ correction enabled instead of entering
106.2602 as VerticalFOV.

Recommended SystemPack behavior:

  NewFOVformula=1

Then set VerticalFOV to the vertical view you want and keep the same value at
all aspect ratios.  SystemPack derives horizontal FOV from the display.
ZenGin's
own FOV formula is not identical to the horizontal-degree convention used by
this document, so an exact 106.2602 horizontal value is not available as
a native Gothic.ini/SystemPack.ini setting.

Target convention for comparison:

  4:3  800x600     horizontal target: 90
  5:4  1280x1024   horizontal target: 86.3048
  16:9 1920x1080   horizontal target: 106.2602
  16:9 2560x1440  horizontal target: 106.2602
  16:9 3840x2160  horizontal target: 106.2602

11. THE ELDER SCROLLS III: MORROWIND (2002)
==============================================================================

This refers to the original Morrowind.exe, not OpenMW.  Vanilla Morrowind
keeps
resolution in the Windows registry and its native widescreen behavior is not
sufficient for the requested fixed FOV mapping.

Use Morrowind FPS Optimizer with the original executable.  Run Morrowind at
least once first so its registry values exist.

In FPS Optimizer choose "Change Morrowind registry settings here" and set:

4:3:

  Screen Width  = 800
  Screen Height = 600

5:4 (1280x1024):

  Screen Width  = 1280
  Screen Height = 1024

16:9 (1920x1080):

  Screen Width  = 1920
  Screen Height = 1080

16:9 (2560x1440):

  Screen Width  = 2560
  Screen Height = 1440

16:9 (3840x2160):

  Screen Width  = 3840
  Screen Height = 2160

Disable novice mode, open the Misc/2 FOV controls, and set:

4:3:

  FOV = 90

5:4 (1280x1024):

  FOV = 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  FOV = 106.2602

Morrowind FPS Optimizer must remain running for its FOV correction to stay
active.  This preserves use of the original Morrowind executable rather than
replacing the engine with OpenMW.

14. FALLOUT 3 (2008)
==============================================================================

Fallout 3 supports widescreen resolutions natively. If the desired mode is
not available in the launcher, edit:

  Documents\My Games\Fallout3\FalloutPrefs.ini

under [Display].

4:3:

  iSize W=800
  iSize H=600

5:4 (1280x1024):

  iSize W=1280
  iSize H=1024

16:9 (1920x1080):

  iSize W=1920
  iSize H=1080

16:9 (2560x1440):

  iSize W=2560
  iSize H=1440

16:9 (3840x2160):

  iSize W=3840
  iSize H=2160

For the project world-camera FOV, edit:

  Documents\My Games\Fallout3\Fallout.ini

under [Display].

4:3:

  fDefaultWorldFOV=90.000000

5:4 (1280x1024):

  fDefaultWorldFOV=86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  fDefaultWorldFOV=106.2602

Fallout 3 has a separate first-person weapon/arms FOV:

  fDefault1stPersonFOV=55.000000

Do not automatically set that value to 106.2602. It controls the
first-person weapon model rather than the world camera, and large values can
cause visible clipping. Adjust it separately only if different weapon framing
is wanted.

The separate fDefaultFOV value affects menus/overlays. Changing it can alter
or misalign interface presentation, so it is not required for this project's
world-camera FOV target.

15. VIETCONG (2003)
==============================================================================

Patch the game to 1.60 and install VCStarter 1.65.1 or newer.  VCStarter is
required for correct widescreen aspect/FOV handling on modern systems.

In VCStarterConfig.exe select the desired resolution:

4:3:

  800x600

5:4 (1280x1024):

  1280x1024
  enable Aspect ratio-fix

16:9 (1920x1080):

  1920x1080
  enable Aspect ratio-fix

16:9 (2560x1440):

  2560x1440
  enable Aspect ratio-fix

16:9 (3840x2160):

  3840x2160
  enable Aspect ratio-fix

VCStarter's Aspect ratio-fix adjusts the widescreen view automatically.  The
game does not expose a verified independent numeric FOV setting, so there is
no honest config or console command into which 106.2602 can be entered.
Do not invent one.

Target convention:

  4:3  (800x600)    fov: 90
  5:4  (1280x1024)  fov: 86.3048
  16:9 (1920x1080)  fov: 106.2602
  16:9 (2560x1440)  fov: 106.2602
  16:9 (3840x2160)  fov: 106.2602

For Vietcong the second line is the desired equivalent view; VCStarter
performs
the aspect correction rather than accepting that exact number directly.

20. SOURCE / VERIFICATION NOTES
==============================================================================
The methods above were checked against engine/source-port documentation,
released source code where available, configuration references, and
established game-specific widescreen documentation.  The references verify
the resolution controls, FOV controls, aspect-ratio behavior, and stated
limitations.  The 4:3 / 5:4 / 16:9 targets are 90 / 86.3048 /
