WIDESCREEN / FOV CONFIG REFERENCE
==============================================================================

SCOPE
------------------------------------------------------------------------------
This reference covers the classic PC games documented in the numbered
sections below. The goal is to use the requested horizontal FOV mapping at
4:3, 5:4, and 16:9. 1920x1080, 2560x1440, and 3840x2160 are all 16:9 and
use the same FOV.

Reference values used by this document:

  4:3  (800x600)    fov: 90
  5:4  (1280x1024)  fov: 86.3048
  16:9 (1920x1080)  fov: 106.2602
  16:9 (2560x1440)  fov: 106.2602
  16:9 (3840x2160)  fov: 106.2602

Unless stated otherwise, "FOV" below means horizontal FOV in degrees.  Some
engines use a different unit, a vertical FOV, or automatic Hor+ scaling; those
cases are called out explicitly.  The values above are the requested project
baseline even when a game's stock/default FOV is different.

==============================================================================
01. DUKE NUKEM 3D (1996) -- EDuke32
==============================================================================

Config files:
Use Setup / Video Setup or the in-game console for vidmode and aspect settings.
Preferred manual overrides: autoexec.cfg

EDuke32 supports arbitrary resolutions. The video mode can be selected from
Setup / Video Setup or changed from the console.

EDuke32 handles widescreen aspect ratios automatically, so the gameplay FOV
should normally remain at its default value of 90. Do not manually convert
90 degrees from 4:3 into 86.3 for 5:4 or 106.26 for 16:9; EDuke32 performs
the aspect-ratio adjustment itself.

==============================================================================
02. QUAKE (1996) -- Mark V
==============================================================================

Config files:
Resolution: put -width and -height on the Mark V shortcut/launcher command
line.
FOV: put fov 90 in id1\autoexec.cfg, or autoexec.cfg in the active mod
directory. Keep the base value at 90 for every aspect ratio.
id1\config.cfg is engine-generated and may be rewritten; use autoexec.cfg
for deliberate manual overrides.

Use the Mark V source port.  Mark V v1099 Revision 4 supports modern
widescreen resolutions while retaining classic Quake behavior.

Mark V automatically applies Hor+ FOV adaptation.  Its "fov" cvar is the base
value that the engine adapts to the current render aspect ratio, so do not put
the already-widened project value 106.2602 directly into the cvar.

4:3:

  mark_v.exe -width 800 -height 600 +fov 90

5:4 (1280x1024):

  mark_v.exe -width 1280 -height 1024 +fov 90

16:9 (1920x1080):

  mark_v.exe -width 1920 -height 1080 +fov 90

16:9 (2560x1440):

  mark_v.exe -width 2560 -height 1440 +fov 90

16:9 (3840x2160):

  mark_v.exe -width 3840 -height 2160 +fov 90

Keep the Mark V base FOV at 90.  The engine's AdaptFovx() function widens the
horizontal view automatically for widescreen.  The same value can be entered
in the console or placed in autoexec.cfg.

Target convention for comparison:

  4:3  (800x600)    horizontal target: 90
  5:4  (1280x1024)  horizontal target: 86.3048
  16:9              horizontal target: 106.2602

Mark V uses its own native aspect-ratio FOV calculation, so keep fov at 90.
The resulting horizontal FOV is derived automatically for 5:4, 16:9, and
other aspect ratios rather than entered directly.

03. QUAKE II (1997) -- Yamagi Quake II
==============================================================================

Config files:
Preferred persistent override: baseq2\autoexec.cfg. Put r_mode,
r_customwidth, r_customheight, horplus, and fov there.
baseq2\config.cfg is engine-managed and may be rewritten. vid_restart is
only needed after changing video values during a running session.

Use a custom video mode.  Yamagi normally has its own Hor+ correction, so turn
that correction off when supplying the final horizontal FOV explicitly.  This
prevents the engine from widening an already widened value.

4:3:

  set r_mode "-1"
  set r_customwidth "800"
  set r_customheight "600"
  set horplus "0"
  set fov "90"
  vid_restart

5:4 (1280x1024):

  set r_mode "-1"
  set r_customwidth "1280"
  set r_customheight "1024"
  set horplus "0"
  set fov "86.3048"
  vid_restart

16:9 (1920x1080):

  set r_mode "-1"
  set r_customwidth "1920"
  set r_customheight "1080"
  set horplus "0"
  set fov "106.2602"
  vid_restart

16:9 (2560x1440):

  set r_mode "-1"
  set r_customwidth "2560"
  set r_customheight "1440"
  set horplus "0"
  set fov "106.2602"
  vid_restart

16:9 (3840x2160):

  set r_mode "-1"
  set r_customwidth "3840"
  set r_customheight "2160"
  set horplus "0"
  set fov "106.2602"
  vid_restart

If using a build that exposes cl_widescreen_fov instead of horplus, disable
that automatic correction for the same reason before setting the final FOV.

06. HALF-LIFE (1998) -- WON / RETAIL VERSION
==============================================================================

Config files:
Resolution: put the -w/-h and related options on the hl.exe shortcut or
launcher command line.
FOV: valve\autoexec.cfg. Put default_fov there for persistence.
valve\config.cfg is engine-generated and may be rewritten, so avoid
relying on manual edits there.

This section is specifically intended for the original pre-Steam Half-Life
WON release, not the 25th Anniversary Steam build.

Install the provided patched Half-Life WON executable:

[Download hl-dark.exe](/files/hl-dark.exe)

[Download sw.dll](/files/sw.dll)

The patch adds proper support for modern widescreen resolutions that are
not handled correctly by the original WON executable. Software rendering
is not supported on Windows 10 or later. OpenGL is recommended for the best
compatibility and overall experience.

Launch config (adjust the resolution as needed):

  hl-dark.exe -console -gl -full -w 1920 -h 1080 -noextracds -32bpp

Create or edit valve\autoexec.cfg:

4:3:

  default_fov 90

5:4 (1280x1024):

  default_fov 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  default_fov 106.2602

You can test the same values from the console with "default_fov <value>".

07. RUNE (2000)
==============================================================================

Config files:
Resolution: System\Rune.ini under the active Windows viewport client section,
using FullscreenViewportX and FullscreenViewportY.
Persistent FOV: System\User.ini, using DesiredFOV and DefaultFOV.
For temporary testing, use the in-game console command "fov <degrees>".

Rune is an Unreal Engine 1 game with a stock 4:3 gameplay FOV of 75 degrees.
Because Rune is normally played in third person, preserve that original
75-degree baseline for the authentic third-person view. If playing in first
person with camerain / behindview 0, use the standard 90-degree 4:3 FPS
baseline instead.

System\Rune.ini:

4:3:

  FullscreenViewportX=800
  FullscreenViewportY=600

5:4 (1280x1024):

  FullscreenViewportX=1280
  FullscreenViewportY=1024

16:9 (1920x1080):

  FullscreenViewportX=1920
  FullscreenViewportY=1080

16:9 (2560x1440):

  FullscreenViewportX=2560
  FullscreenViewportY=1440

16:9 (3840x2160):

  FullscreenViewportX=3840
  FullscreenViewportY=2160

OPTION 1 -- ORIGINAL THIRD-PERSON VIEW

Preserve Rune's stock 75-degree horizontal FOV at 4:3 and widen it
aspect-correctly for other aspect ratios.

System\User.ini:

4:3 (800x600):

  DesiredFOV=75.000000
  DefaultFOV=75.000000

5:4 (1280x1024):

  DesiredFOV=71.4601
  DefaultFOV=71.4601

16:9 (1920x1080, 2560x1440 and 3840x2160):

  DesiredFOV=91.3085
  DefaultFOV=91.3085

Temporary console equivalents:

  4:3   fov 75
  5:4   fov 71.4601
  16:9  fov 91.3085

These values preserve approximately the same vertical view as Rune's original
75-degree 4:3 presentation.

OPTION 2 -- FIRST-PERSON PLAY

For first-person play, use the standard 90-degree 4:3 FPS baseline. This is
appropriate when using camerain or behindview 0 to bring the camera into
first person.

System\User.ini:

4:3 (800x600):

  DesiredFOV=90.000000
  DefaultFOV=90.000000

5:4 (1280x1024):

  DesiredFOV=86.3048
  DefaultFOV=86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  DesiredFOV=106.2602
  DefaultFOV=106.2602

Temporary console equivalents:

  4:3   fov 90
  5:4   fov 86.3048
  16:9  fov 106.2602

Useful first-person commands:

  camerain
    Moves the camera inward and can be bound to a key for convenient
    first-person play.

  cameraout
    Moves the camera back outward.

  behindview 0
    Switches to first-person view.

  behindview 1
    Restores the normal third-person view.

Rune's scripted cutscenes can override the player FOV, so their framing is not
necessarily corrected by User.ini or the temporary fov command.

Original Rune/Rune Gold can accept widescreen modes through the INI, but the
classic D3D7 renderer may reject very high modes. If 2560x1440 or 3840x2160 is
not accepted, keep a supported 16:9 game mode and use a wrapper such as
dgVoodoo2 to scale or present the game at a higher output resolution. The FOV
depends on aspect ratio, not pixel count, so all listed 16:9 modes use the same
FOV within the selected third-person or first-person option.

09. GOTHIC (2001)
==============================================================================

Config files:
Resolution: Gothic\System\Gothic.ini under [VIDEO].
FOV behavior: Gothic\System\SystemPack.ini. Keep NewFOVformula enabled and
use its VerticalFOV control rather than entering the horizontal target
directly.

Use Union/SystemPack for reliable modern widescreen support.  Set resolution
in Gothic\System\Gothic.ini.

[VIDEO]

4:3:

  zVidResFullscreenX=800
  zVidResFullscreenY=600
  zVidResFullscreenBPP=32

5:4 (1280x1024):

  zVidResFullscreenX=1280
  zVidResFullscreenY=1024
  zVidResFullscreenBPP=32

16:9 (1920x1080):

  zVidResFullscreenX=1920
  zVidResFullscreenY=1080
  zVidResFullscreenBPP=32

16:9 (2560x1440):

  zVidResFullscreenX=2560
  zVidResFullscreenY=1440
  zVidResFullscreenBPP=32

16:9 (3840x2160):

  zVidResFullscreenX=3840
  zVidResFullscreenY=2160
  zVidResFullscreenBPP=32

SystemPack.ini does not expose the same horizontal-degree control used by the
reference values above.  It exposes VerticalFOV and calculates horizontal FOV
from the aspect ratio.  Keep Hor+ correction enabled instead of entering
106.2602 as VerticalFOV.

Recommended SystemPack behavior:

  NewFOVformula=1

Then set VerticalFOV to the vertical view you want and keep the same value at
all aspect ratios.  SystemPack derives horizontal FOV from the display.
ZenGin's
own FOV formula is not identical to the horizontal-degree convention used by
this document, so an exact 106.2602 horizontal value is not available as
a native Gothic.ini/SystemPack.ini setting.

Target convention for comparison:

  4:3  800x600     horizontal target: 90
  5:4  1280x1024   horizontal target: 86.3048
  16:9 1920x1080   horizontal target: 106.2602
  16:9 2560x1440  horizontal target: 106.2602
  16:9 3840x2160  horizontal target: 106.2602

12. THE ELDER SCROLLS III: MORROWIND (2002)
==============================================================================

Config files:
Resolution is stored in the Windows registry, not in Morrowind.ini. Use
Morrowind FPS Optimizer to edit the registry values.
Set the requested FOV through FPS Optimizer's Misc/2 FOV controls; no
separate text config file is used by this method.

This refers to the original Morrowind.exe, not OpenMW.  Vanilla Morrowind
keeps
resolution in the Windows registry and its native widescreen behavior is not
sufficient for the requested fixed FOV mapping.

Use Morrowind FPS Optimizer with the original executable.  Run Morrowind at
least once first so its registry values exist.

In FPS Optimizer choose "Change Morrowind registry settings here" and set:

4:3:

  Screen Width  = 800
  Screen Height = 600

5:4 (1280x1024):

  Screen Width  = 1280
  Screen Height = 1024

16:9 (1920x1080):

  Screen Width  = 1920
  Screen Height = 1080

16:9 (2560x1440):

  Screen Width  = 2560
  Screen Height = 1440

16:9 (3840x2160):

  Screen Width  = 3840
  Screen Height = 2160

Disable novice mode, open the Misc/2 FOV controls, and set:

4:3:

  FOV = 90

5:4 (1280x1024):

  FOV = 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  FOV = 106.2602

Morrowind FPS Optimizer must remain running for its FOV correction to stay
active.  This preserves use of the original Morrowind executable rather than
replacing the engine with OpenMW.

16. VIETCONG (2003)
==============================================================================

Config files:
Set resolution and Aspect ratio-fix in VCStarterConfig.exe.
VCStarter performs the aspect correction itself; there is no separate
numeric FOV value to put in a Vietcong config file for this method.

Patch the game to 1.60 and install VCStarter 1.65.1 or newer.  VCStarter is
required for correct widescreen aspect/FOV handling on modern systems.

In VCStarterConfig.exe select the desired resolution:

4:3:

  800x600

5:4 (1280x1024):

  1280x1024
  enable Aspect ratio-fix

16:9 (1920x1080):

  1920x1080
  enable Aspect ratio-fix

16:9 (2560x1440):

  2560x1440
  enable Aspect ratio-fix

16:9 (3840x2160):

  3840x2160
  enable Aspect ratio-fix

VCStarter's Aspect ratio-fix adjusts the widescreen view automatically.  The
game does not expose a verified independent numeric FOV setting, so there is
no honest config or console command into which 106.2602 can be entered.
Do not invent one.

Target convention:

  4:3  (800x600)    fov: 90
  5:4  (1280x1024)  fov: 86.3048
  16:9 (1920x1080)  fov: 106.2602
  16:9 (2560x1440)  fov: 106.2602
  16:9 (3840x2160)  fov: 106.2602

For Vietcong the second line is the desired equivalent view; VCStarter
performs
the aspect correction rather than accepting that exact number directly.

==============================================================================
17. RED FACTION (2001)
==============================================================================

Config files:
Resolution: set it in AlpineFactionLauncher.exe.
FOV: enter r_fov in the Alpine Faction in-game console. The documented
method does not require editing an original Red Faction config file.

Use Alpine Faction.  It supports arbitrary widescreen resolutions and exposes
the horizontal FOV directly in degrees.

Set resolution in AlpineFactionLauncher.exe:

4:3:

  800x600

5:4 (1280x1024):

  1280x1024

16:9 (1920x1080):

  1920x1080

16:9 (2560x1440):

  2560x1440

16:9 (3840x2160):

  3840x2160

Then open the in-game console and set:

4:3:

  r_fov 90

5:4 (1280x1024):

  r_fov 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  r_fov 106.2602

Alpine can also perform automatic Hor+ scaling with "r_fov 0".  Do not use
automatic scaling and an already widened manual value at the same time.

The first-person weapon FOV is separate (r_fpgunfov); leave it at its default
unless you specifically want to alter weapon-model framing as well.

Resolution: cam.cfg in the game directory, using game_screen_size.
Exact FOV override: cam_ext.cfg in the game directory, using fov.

stored in cam_ext.cfg.

  game_screen_size 800 600

  game_screen_size 1280 1024

16:9 (1920x1080):

  game_screen_size 1920 1080

16:9 (2560x1440):

  game_screen_size 2560 1440

16:9 (3840x2160):

  game_screen_size 3840 2160

cam_ext.cfg:

4:3:

  fov 90

5:4 (1280x1024):

  fov 86.3048

16:9 (1920x1080, 2560x1440 and 3840x2160):

  fov 106.2602

NewDark can normally detect an aspect-correct FOV itself.  The explicit fov
line above is useful when you want the exact project values rather than the
automatic value.
