WIDESCREEN / FOV CONFIG REFERENCE
==============================================================================
SCOPE
------------------------------------------------------------------------------
Scope: the 17 games currently documented by the game-console repository.
The goal is to use the requested horizontal FOV mapping at 4:3 and 16:9.
1920x1080, 2560x1440, and 3840x2160 are all 16:9 and use the same FOV.

Reference values used by this document:

  4:3  (800x600)   fov: 90
  16:9 (1920x1080) fov: 106.270273206
  16:9 (2560x1440) fov: 106.270273206
  16:9 (3840x2160) fov: 106.270273206

Unless stated otherwise, "FOV" below means horizontal FOV in degrees.  Some
engines use a different unit, a vertical FOV, or automatic Hor+ scaling; those
cases are called out explicitly.  The values above are the requested project
baseline even when a game's stock/default FOV is different.
==============================================================================
01. DUKE NUKEM 3D -- EDuke32
==============================================================================

EDuke32 supports arbitrary resolutions.  The video mode can be selected from
Setup / Video Setup or changed from the console.

4:3:

  vidmode 800 600 32 1
  FOV: 90

16:9 (1920x1080):

  vidmode 1920 1080 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.270273206

16:9 (2560x1440):

  vidmode 2560 1440 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.270273206

16:9 (3840x2160):

  vidmode 3840 2160 32 1
  r_usenewaspect 1
  r_screenaspect 1609
  FOV: 106.270273206

Set FOV in the EDuke32 display options.  Modern EDuke32 exposes the gameplay
FOV in degree-style units with 90 as the default.

Older Polymer-only builds expose r_pr_fov instead.  That command uses BUILD
angle units, not degrees: 512 is about 90 degrees.  The requested 16:9 value
cannot be represented exactly by that integer-style scale; about 605 BUILD
units is the nearest value.  Do not enter 106.270273206 into r_pr_fov.
==============================================================================
02. QUAKE -- GLQuake
==============================================================================

GLQuake accepts custom width and height on the command line and the normal
Quake fov cvar accepts a floating-point horizontal FOV.

4:3:

  glquake.exe -width 800 -height 600 +fov 90

16:9 (1920x1080):

  glquake.exe -width 1920 -height 1080 +fov 106.270273206

16:9 (2560x1440):

  glquake.exe -width 2560 -height 1440 +fov 106.270273206

16:9 (3840x2160):

  glquake.exe -width 3840 -height 2160 +fov 106.270273206

The fov value can also be entered in the console and placed in config.cfg.
Original GLQuake is an old renderer; a modern source port is preferable if a
particular GPU/driver refuses a high-resolution mode.
==============================================================================
03. QUAKE II -- Yamagi Quake II
==============================================================================

Use a custom video mode.  Yamagi normally has its own Hor+ correction, so turn
that correction off when supplying the final horizontal FOV explicitly.  This
prevents the engine from widening an already widened value.

4:3:

  set r_mode "-1"
  set r_customwidth "800"
  set r_customheight "600"
  set horplus "0"
  set fov "90"
  vid_restart

16:9 (1920x1080):

  set r_mode "-1"
  set r_customwidth "1920"
  set r_customheight "1080"
  set horplus "0"
  set fov "106.270273206"
  vid_restart

16:9 (2560x1440):

  set r_mode "-1"
  set r_customwidth "2560"
  set r_customheight "1440"
  set horplus "0"
  set fov "106.270273206"
  vid_restart

16:9 (3840x2160):

  set r_mode "-1"
  set r_customwidth "3840"
  set r_customheight "2160"
  set horplus "0"
  set fov "106.270273206"
  vid_restart

If using a build that exposes cl_widescreen_fov instead of horplus, disable
that automatic correction for the same reason before setting the final FOV.

04. UNREAL (1998)
==============================================================================

For reliable widescreen operation on current systems, the OldUnreal 227 patch
is recommended.  Resolution is stored in System\Unreal.ini; FOV is stored in
System\User.ini.

System\Unreal.ini, under the active viewport client section:

4:3:

  FullscreenViewportX=800
  FullscreenViewportY=600

16:9 (1920x1080):

  FullscreenViewportX=1920
  FullscreenViewportY=1080

16:9 (2560x1440):

  FullscreenViewportX=2560
  FullscreenViewportY=1440

16:9 (3840x2160):

  FullscreenViewportX=3840
  FullscreenViewportY=2160

System\User.ini, under [Engine.PlayerPawn]:

4:3:

  DesiredFOV=90.000000
  DefaultFOV=90.000000

16:9 (1920x1080, 2560x1440 and 3840x2160):

  DesiredFOV=106.270273206
  DefaultFOV=106.270273206

The console command "fov <value>" can be used for a quick test before making
the User.ini change permanent.

06. HALF-LIFE -- WON / RETAIL VERSION
==============================================================================

This section is deliberately for the original pre-Steam WON release, not the
25th Anniversary Steam build.

Install the Half-Life WON Resolution FOV MP3 Patch for the matching executable
version.  WON 1.1.1.0 is the usual final retail/WON build.  The patch enables
modern widescreen modes that the unmodified WON executable does not handle
properly.

The patch can include hl_fov_fix.asi, which automatically widens FOV according
to the current aspect ratio.  For the exact manual values in this document,
do not load hl_fov_fix.asi; otherwise the automatic correction and the manual
FOV can be applied together.

Launch examples:

4:3:

  hl.exe -gl -full -w 800 -h 600
  add: -lw 800 -lh 600 -noextracds -32bpp

16:9 (1920x1080):

  hl.exe -gl -full -w 1920 -h 1080
  add: -lw 1920 -lh 1080 -noextracds -32bpp

16:9 (2560x1440):

  hl.exe -gl -full -w 2560 -h 1440
  add: -lw 2560 -lh 1440 -noextracds -32bpp

16:9 (3840x2160):

  hl.exe -gl -full -w 3840 -h 2160
  add: -lw 3840 -lh 2160 -noextracds -32bpp

Create or edit valve\autoexec.cfg:

4:3:

  default_fov 90

16:9 (1920x1080, 2560x1440 and 3840x2160):

  default_fov 106.270273206

You can test the same values from the console with "default_fov <value>".

07. DEUS EX
==============================================================================

Deus Ex is Unreal Engine 1.  Resolution is configured in System\DeusEx.ini and
persistent FOV in System\User.ini.  A modern renderer or Kentie's launcher can
help if the original renderer rejects the requested widescreen mode.

System\DeusEx.ini, under the active viewport client section:

4:3:

  FullscreenViewportX=800
  FullscreenViewportY=600

16:9 (1920x1080):

  FullscreenViewportX=1920
  FullscreenViewportY=1080

16:9 (2560x1440):

  FullscreenViewportX=2560
  FullscreenViewportY=1440

16:9 (3840x2160):

  FullscreenViewportX=3840
  FullscreenViewportY=2160

System\User.ini, under [DeusEx.DeusExPlayer]:

4:3:

  DesiredFOV=90.000000
  DefaultFOV=90.000000

16:9 (1920x1080, 2560x1440 and 3840x2160):

  DesiredFOV=106.270273206
  DefaultFOV=106.270273206

Deus Ex originally uses a narrower default FOV.  The settings above knowingly
replace that stock value with this project's requested 90-degree 4:3 baseline.

08. GOTHIC
==============================================================================

Use Union/SystemPack for reliable modern widescreen support.  Set resolution
in Gothic\System\Gothic.ini.

[VIDEO]

4:3:

  zVidResFullscreenX=800
  zVidResFullscreenY=600
  zVidResFullscreenBPP=32

16:9 (1920x1080):

  zVidResFullscreenX=1920
  zVidResFullscreenY=1080
  zVidResFullscreenBPP=32

16:9 (2560x1440):

  zVidResFullscreenX=2560
  zVidResFullscreenY=1440
  zVidResFullscreenBPP=32

16:9 (3840x2160):

  zVidResFullscreenX=3840
  zVidResFullscreenY=2160
  zVidResFullscreenBPP=32

SystemPack.ini does not expose the same horizontal-degree control used by the
reference values above.  It exposes VerticalFOV and calculates horizontal FOV
from the aspect ratio.  Keep Hor+ correction enabled instead of entering
106.270273206 as VerticalFOV.

Recommended SystemPack behavior:

  NewFOVformula=1

Then set VerticalFOV to the vertical view you want and keep the same value at
both resolutions.  SystemPack expands the horizontal view for 16:9.  ZenGin's
own FOV formula is not identical to the horizontal-degree convention used by
this document, so an exact 106.270273206 horizontal value is not available as
a native Gothic.ini/SystemPack.ini setting.

Target convention for comparison:

  4:3  800x600    horizontal target: 90
  16:9 1920x1080  horizontal target: 106.270273206
  16:9 2560x1440  horizontal target: 106.270273206
  16:9 3840x2160  horizontal target: 106.270273206

==============================================================================

Use Union/SystemPack.  Set resolution in Gothic II\System\Gothic.ini.

If required, enable the extended resolution menu:

  extendedMenu=1

[VIDEO]

4:3:

  zVidResFullscreenX=800
  zVidResFullscreenY=600
  zVidResFullscreenBPP=32

16:9 (1920x1080):

  zVidResFullscreenX=1920
  zVidResFullscreenY=1080
  zVidResFullscreenBPP=32

16:9 (2560x1440):

  zVidResFullscreenX=2560
  zVidResFullscreenY=1440
  zVidResFullscreenBPP=32

16:9 (3840x2160):

  zVidResFullscreenX=3840
  zVidResFullscreenY=2160
  zVidResFullscreenBPP=32

As with Gothic, SystemPack controls VerticalFOV and derives horizontal FOV
from
the display aspect ratio.  Do not put 106.270273206 into VerticalFOV.

Recommended SystemPack behavior:

  NewFOVformula=1

Keep the same VerticalFOV at 4:3 and 16:9 so the 16:9 view becomes Hor+.
ZenGin's FOV calculation does not provide an exact native horizontal setting
matching this document's degree convention.

Target convention for comparison:

10. GOTHIC 3
==============================================================================

Edit Gothic 3\Ini\ge3.ini.  The [Window] block controls resolution and
Camera.FOV is expressed in degrees.

4:3:

  [Window]
  Right=800
  Bottom=600
  Fullscreen=true

  Camera.FOV=90

16:9 (1920x1080):

  [Window]
  Right=1920
  Bottom=1080
  Fullscreen=true

  Camera.FOV=106.270273206

16:9 (2560x1440):

  [Window]
  Right=2560
  Bottom=1440
  Fullscreen=true

  Camera.FOV=106.270273206

16:9 (3840x2160):

  [Window]
  Right=3840
  Bottom=2160
  Fullscreen=true

  Camera.FOV=106.270273206

Keep the existing Left=0 and Top=0 values unless you intentionally want a
window offset.  Gothic 3's stock Camera.FOV is narrower; the values above use
the requested project baseline.

11. THE ELDER SCROLLS III: MORROWIND
==============================================================================

This refers to the original Morrowind.exe, not OpenMW.  Vanilla Morrowind
keeps
resolution in the Windows registry and its native widescreen behavior is not
sufficient for the requested fixed FOV mapping.

Use Morrowind FPS Optimizer with the original executable.  Run Morrowind at
least once first so its registry values exist.

In FPS Optimizer choose "Change Morrowind registry settings here" and set:

4:3:

  Screen Width  = 800
  Screen Height = 600

16:9 (1920x1080):

  Screen Width  = 1920
  Screen Height = 1080

16:9 (2560x1440):

  Screen Width  = 2560
  Screen Height = 1440

16:9 (3840x2160):

  Screen Width  = 3840
  Screen Height = 2160

Disable novice mode, open the Misc/2 FOV controls, and set:

4:3:

  FOV = 90

16:9 (1920x1080, 2560x1440 and 3840x2160):

  FOV = 106.270273206

Morrowind FPS Optimizer must remain running for its FOV correction to stay
active.  This preserves use of the original Morrowind executable rather than
replacing the engine with OpenMW.

14. VIETCONG (2003)
==============================================================================

Patch the game to 1.60 and install VCStarter 1.65.1 or newer.  VCStarter is
required for correct widescreen aspect/FOV handling on modern systems.

In VCStarterConfig.exe select the desired resolution:

4:3:

  800x600

16:9 (1920x1080):

  1920x1080
  enable Aspect ratio-fix

16:9 (2560x1440):

  2560x1440
  enable Aspect ratio-fix

16:9 (3840x2160):

  3840x2160
  enable Aspect ratio-fix

VCStarter's Aspect ratio-fix adjusts the widescreen view automatically.  The
game does not expose a verified independent numeric FOV setting, so there is
no honest config or console command into which 106.270273206 can be entered.
Do not invent one.

Target convention:

  4:3  (800x600)   fov: 90
  16:9 (1920x1080) fov: 106.270273206
  16:9 (2560x1440) fov: 106.270273206
  16:9 (3840x2160) fov: 106.270273206

For Vietcong the second line is the desired equivalent view; VCStarter
performs
the aspect correction rather than accepting that exact number directly.

15. RED FACTION (2001)
==============================================================================

Use Alpine Faction.  It supports arbitrary widescreen resolutions and exposes
the horizontal FOV directly in degrees.

Set resolution in AlpineFactionLauncher.exe:

4:3:

  800x600

16:9 (1920x1080):

  1920x1080

16:9 (2560x1440):

  2560x1440

16:9 (3840x2160):

  3840x2160

Then open the in-game console and set:

4:3:

  r_fov 90

16:9 (1920x1080, 2560x1440 and 3840x2160):

  r_fov 106.270273206

Alpine can also perform automatic Hor+ scaling with "r_fov 0".  Do not use
automatic scaling and an already widened manual value at the same time.

The first-person weapon FOV is separate (r_fpgunfov); leave it at its default
unless you specifically want to alter weapon-model framing as well.

16. THIEF: THE DARK PROJECT / GOLD -- NewDark
==============================================================================

Use NewDark.  Resolution is stored in cam.cfg and an explicit FOV override is
stored in cam_ext.cfg.

cam.cfg:

4:3:

  game_screen_size 800 600

16:9 (1920x1080):

  game_screen_size 1920 1080

16:9 (2560x1440):

  game_screen_size 2560 1440

16:9 (3840x2160):

  game_screen_size 3840 2160

cam_ext.cfg:

4:3:

  fov 90

16:9 (1920x1080, 2560x1440 and 3840x2160):

  fov 106.270273206

NewDark can normally detect an aspect-correct FOV itself.  The explicit fov
line above is useful when you want the exact project values rather than the
automatic value.
