RED FACTION (2001) -- ORIGINAL PC CONSOLE COMMAND REFERENCE
==============================================================================

IMPORTANT
------------------------------------------------------------------------------
Scope: Volition's original Red Faction PC game through official client v1.20.
Dash Faction, Pure Faction, Alpine Faction, console ports, and later Red
Faction games are not used as the base command reference.

==============================================================================
1. CONSOLE BASICS
==============================================================================

Press ~ to show or hide the console in the PC client. The stock console is
also available to dedicated servers. Command availability differs between
single-player clients, multiplayer clients, servers, and rcon.
  - ~ — show/hide the client console
  - Tab — complete a partially entered command
  - F3 — recall/display the most recently entered command
  - Up — previous command in history
  - Down — next command in history
  - Page Up — scroll the console log backward
  - Page Down — scroll the console log forward


==============================================================================
2. SINGLE-PLAYER CHEATS / CAMERA
==============================================================================

vivalahelvig
  Toggles god mode. This is an undocumented stock command.

bighugmug
  Gives the player all weapons and maximum ammunition. Undocumented.

heehoo
  Toggles player movement between normal walking and flying. Undocumented.

camera1
  Sets first-person camera mode. Undocumented.

camera2
  Sets free-camera mode. Undocumented.

camera3
  Sets third-person camera mode. Undocumented.

kill
  Kills the local player.


==============================================================================
3. BASE GAME CLIENT / SERVER COMMANDS
==============================================================================

help
  Displays the available stock console command list.

?
  Alias for help.

man
  Alias for help.

info
  Displays level, time, frame-rate, client, ping, and related information.

level <file.rfl>
  Loads a level in single player when local, or changes a server level.

name <player-name>
  Changes the local player name; on a listen server it also affects the server
  name.

say <message>
  Sends a chat message to everyone on the server.

team_say <message>
  Sends chat only to the local player's team.

team "red"
  Changes to the red team in a team game.

team "blue"
  Changes to the blue team in a team game.

rate <number-or-preset>
  Sets the client/server network update rate.

simultaneous_ping <integer>
  Sets how many multiplayer servers are queried simultaneously.

dump_tga
  Toggles screenshot output between TGA and JPG for Print Screen.

quit
  Exits the client or dedicated server without confirmation.


==============================================================================
4. SERVER ADMINISTRATION
==============================================================================

kick <player-name>
  Kicks the specified player without adding a ban.

ban <player-name>
  Kicks the player and adds the player's IP address to banlist.txt.

ban_ip <address-or-range>
  Bans an IP address or range and kicks matching connected players.

rcon_request <password>
  Requests remote-console privilege from a dedicated server.

rcon <command>
  Runs a server console command after successful rcon_request authentication.


==============================================================================
5. ORIGINAL-VS-COMMUNITY-PORT DISTINCTION
==============================================================================

Modern Red Faction community ports add many useful commands such as map
aliases, FPS controls, HUD toggles, spectating, command search, and command
dumping. They are deliberately omitted here because they are not part of the
official v1.20 executable.
For the stock game, help (also ? or man) is the built-in discovery command.
The Red Faction Wiki's Base Game table is the best public matrix for checking
whether a command is valid in SP, MP client, server, or rcon context.
